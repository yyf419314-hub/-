## 📝 核心实验结论与思考

### 1. 概率优势与仓位管理（Task 1）
* **量化底层逻辑**：量化不是预测明天的绝对涨跌，而是将交易逻辑转化为“假设 $\to$ 数据 $\to$ 验证 $\to$ 规则”的闭环，赚取统计学上的正期望。
* **索普博弈启示**：即使拥有 2% 的微弱胜率优势，盲目重仓（如 25% 仓位）长期依然会因连亏序列而爆仓；必须配合**凯利公式（科学仓位控制）**才能将概率优势转化为复利增长。

### 2. 收益率分布与风险特征（Task 2）
* **真实波幅（TR）**：相比常规最高价与最低价之差，TR 将前一日收盘价纳入考量，能有效捕获隔夜跳空缺口带来的真实价格风险。
* **尖峰肥尾（Fat Tails）**：
  * **苹果 (AAPL)**：日常日收益率波动极小，但峰度高达 3.19（明显尖峰肥尾），少数极端交易日（如财报发布日、指数调仓日）会出现单日超 5% 的踩踏出逃。
  * **美光科技 (MU)**：属于高波动资产（年化波动率超 80%），日收益率呈现正偏（Skewness > 0），事件驱动爆发力强，需重点控制基础敞口。
